# Somsy — Private Movement Ritual

Somsy is a private, mobile-first virtual workout assistant for a progressive
30-day equipment-free home program. It includes:

- All 30 daily sessions, including strength, cardio, mobility, intervals,
  recovery and reassessment
- A full-screen workout runner with automatic work/rest timers
- Exercise start/finish demonstrations and concise form cues
- Optional voice announcements and countdown sounds
- Daily weight check-ins before each workout
- A private, durable log of weight, completed workouts and dates
- A compact personal progress ledger

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

The live site is owner-only. Exercise reference images are drawn from
[Free Exercise DB](https://github.com/yuhonas/free-exercise-db), an open
public-domain exercise dataset. The Somsy brand art and social sharing card
were created specifically for this project.
