# FORM30

FORM30 is a mobile-first virtual workout assistant for a progressive 30-day,
equipment-free home program. It includes:

- All 30 daily sessions, including strength, cardio, mobility, intervals,
  recovery and reassessment
- A full-screen workout runner with automatic work/rest timers
- Exercise start/finish demonstrations and concise form cues
- Optional voice announcements and countdown sounds
- Device-local workout completion tracking
- Nutrition targets and realistic fat-loss guidance

## Local development

```bash
pnpm install
pnpm dev
```

## Production build

```bash
pnpm build
```

Exercise reference images are drawn from
[Free Exercise DB](https://github.com/yuhonas/free-exercise-db), an open
public-domain exercise dataset. The FORM30 brand art and social sharing card
were created specifically for this project.
